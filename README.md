# 🌿 后院管理2

后院菜地管理 App — React + TypeScript + Vite + Firebase

## 技术栈

- **前端**: React 18 + TypeScript + Vite
- **数据库**: Firebase Firestore（实时同步，多设备共享）
- **部署**: Vercel（自动从 GitHub 部署）

---


## 功能

- 🗺️ **地图** — 多块菜地管理，上传平面图，Canvas 标注蔬菜位置
- 🧺 **采摘** — 记录每次采摘，筛选统计
- 📒 **支出** — 记录菜园投入，分类账本
- 📊 **统计** — 采摘排行、支出分类、月度对照表
- ☁️ **云同步** — Firebase 实时同步，多设备共享数据
